# 스플래시 애니메이션 핸드오프

피그마에서 만든 스플래시 애니메이션을 앱(vium_app)에 구현하기 위한 정보 모음.
레퍼런스 영상: [splash-reference.mp4](./splash-reference.mp4) (402px 폭, 30fps)

---

## 1. 피그마 위치

- 파일: `https://www.figma.com/design/3vvcWJtR8AmJeIAMP7EIsc/` (fileKey `3vvcWJtR8AmJeIAMP7EIsc`)
- 스플래시 프레임: **UI pages** 페이지 → `splash` (`1236:1550`, 402×874)
- 이동할 메인(시작) 화면: **UI pages** → `Frame` (`104:1606`) — 로고 + 캐릭터 + "눌러서 시작하기" 버튼
- 식재료 아이콘 컴포넌트: **Design System** 페이지 → `falling-ingredients` 프레임 (`3015:7`)
  - `ingredient/tomato` 3015:8, `onion` 3015:12, `potato` 3015:18, `carrot` 3015:24,
    `broccoli` 3015:32, `mushroom` 3015:38, `leaf` 3015:44, `egg` 3015:47 (각 64×64)
- 피그마 모션(키프레임)은 `get_motion_context`(nodeId `1236:1550`, recursive)로 CSS/motion 코드 형태로 다시 뽑을 수 있음.

## 2. 앱 현재 상태 (참고)

- 라우트: `app/(auth)/splash.tsx` → `src/features/auth/screens/SplashPage.tsx`
  - 지금은 정적 화면 (로고 + "나만의 폐기관리 도우미" + 시작하기 버튼, `router.push('/login')`)
- 이미 설치됨: `react-native-reanimated ~4.1.1`, `react-native-svg`, `expo-splash-screen`
- 이미 있는 에셋: `assets/tomato.svg`, `onion.svg`, `potato.svg`(캐릭터), `assets/icons/ViUM.svg`(로고), Paperlogy 폰트
- **식재료 아이콘 8종은 아직 앱 에셋에 없음** → 피그마 `falling-ingredients`에서 SVG로 export 필요
- 피그마의 `104:1606`(메인) = 앱의 `SplashPage` 정적 화면에 해당. 애니메이션이 끝나면 그 상태로 자연스럽게 이어지는 구조.

## 4. 타임라인 (총 3.05초 → 메인으로 디졸브 0.3초)

시간 단위 초. 이징 이름은 피그마 기준 (아래 5번에 cubic-bezier 값).

### A. 식재료 비 (0.2 ~ 1.45s) — 42개
- 화면 아래쪽(y≈570~850)에 쌓이는 더미. 행별 개수(아래부터) 7,7,6,6,5,4,4,3. 크기 0.85~1.2배(약 54~77px), 각자 랜덤 회전(당근·잎은 ±70°, 나머지 ±30°).
- 종류 비율: 토마토·양파·감자 많이, 당근·브로콜리·버섯·잎·달걀 섞어서.
- 각 조각 i (아래 행부터 순서대로, n=42):
  - 시작 `st = 0.2 + i·(0.68/n) + rand(0~0.03)`
  - Y: `-(화면 위 밖)` → 0 (st → st+0.4, ease-in), 바운스 -9px (+0.09, ease-out) → 0 (+0.18, ease-in)
  - 회전: 랜덤 ±(80~200)° → 0 (st → st+0.4, ease-out)
  - 착지 순간 스쿼시: scale (1.12, 0.88) → 1 (착지 → +0.18, ease-out)
  - 모든 조각 1.45s까지 착지 완료

### B. 터지기 직전 기모으기 (1.45 ~ 1.6s)
- 전체 더미: Y +6px, scale (1.12, 0.86) (ease-in)

### C. 폭발 (1.6 ~ 2.25s)
- 폭발 원점 = 배경 원 중심 (201, 362)
- 각 조각 시작 `ex = 1.6 + rand(0~0.05)`, 길이 0.6s, 이징 BURST
  - X: 원점에서 바깥 방향으로 (240~460)·0.95 px
  - Y: 무조건 화면 위로 빠지게 `-(현재 y + 100~320)`
  - 회전: 왼쪽 조각은 +, 오른쪽은 − 방향으로 220~520°
  - scale: 1.12×0.86 → 1.15 (+0.15, ease-out) → 0.5 (+0.6, ease-in)
  - opacity: 1 유지하다 ex+0.25 → ex+0.6 에 0 (ease-in)
- 파티클 18개 (원 6~15px, 3개 중 1개는 알약 모양): 원점에서 반지름 130~260px로 방사 (1.6 ~ 2.15s, BURST), scale 0.3 → 1.2 → 0.4, opacity 0 → 1 → 0, 회전 랜덤
  - 색: `#B2E194` `#F4685A` `#F4CA90` `#8DC66B` `#FFD966`

### D. 배경 원 등장 (1.56 ~ 2.0s)
- opacity 0 → 1 (1.56 → 1.64), scale 0.2 → 1 (1.56 → 2.0, ease-out-back)

### E. 캐릭터 착지 (1.78 ~ 2.6s)
- 순서/시작: 토마토 1.78, 양파 1.88, 감자 1.98
- 각 캐릭터 시작 t, 착지 land = t + 0.32
  - opacity 0 → 1 (t → t+0.08)
  - Y: -340 → 0 (ease-in) → -16 (+0.12, ease-out) → 0 (+0.24, ease-in)
  - scale: (0.9,1.1) → (0.92,1.08) at land → (1.15,0.85) (+0.06) → 1 (+0.35, ease-out-back)
- 각 그림자: opacity 0 → 0.7 (t → land), scale 0.3 → 1 (land) → (1.15,1) (+0.06) → 1 (+0.3)

### F. 로고 (2.2 ~ 2.83s)
- 글자별 순차 V(2.2) → i(2.27) → U(2.34) → M(2.41)
  - opacity 0 → 1 (+0.12), Y +26 → 0 (+0.42, ease-out-back), scale 0.3 → 1 (+0.42, ease-out-back)
- 태그라인: opacity 0 → 1, Y +10 → 0 (2.5 → 2.8, ease-out)

### G. 전환
- 3.05s에 메인 화면으로 디졸브 0.3s (ease-out). 메인에선 버튼만 새로 보임.

## 7. 구현 시 주의/팁

- **성능**: 42개 + 파티클 18개 동시 애니메이션. Reanimated `useSharedValue` 하나(진행도 0→3.05)로 돌리고 각 조각은 `useAnimatedStyle`에서 계산하면 가벼움. SVG를 그대로 42개 쓰면 무거울 수 있으니 PNG(@2x/@3x)로 export 하거나 `react-native-svg` 컴포넌트를 memo 처리.
- **랜덤 값**: 피그마는 시드 고정 랜덤. 앱에서도 시드 고정(또는 미리 계산한 배열)으로 매번 같은 연출이 나오게 하는 걸 추천.
- **화면 크기**: 수치는 402×874 기준. 기기 폭/높이 비율로 스케일하거나, 원 중심·더미 영역을 화면 비율로 잡기.
- **네이티브 스플래시**: `expo-splash-screen`의 정적 스플래시(흰 배경)를 먼저 보여주고 숨긴 뒤 이 애니메이션 화면으로 바로 넘어가게. 첫 프레임은 빈 흰 화면이라 이어붙이기 쉬움.
- **접근성**: 시스템 "동작 줄이기"가 켜져 있으면(`AccessibilityInfo.isReduceMotionEnabled`) 애니메이션 건너뛰고 바로 메인 상태 보여주기.
- **프로젝트 규칙(AGENTS.md / CLAUDE.local.md)과 부딪히는 부분 — 구현 전에 사용자에게 확인할 것**
  - 애니메이션 컴포넌트는 `src/features/auth/ui/`에 두고 `SplashPage`에서 사용 (shared/ui 아님).
  - "인라인 스타일 금지" 규칙이 있지만 Reanimated `useAnimatedStyle`은 `style`로 넘겨야 함 → 레이아웃은 `className`, 움직임만 animated style로 나누는 걸로 합의 필요.
  - 색 하드코딩 금지: 배경 원 green-100, 그림자 green-200은 토큰 있음(`primary/green-*`). 아이콘·파티클 색은 SVG/에셋 안에 두거나, 토큰에 없으면 사용자에게 물어보기.
  - `SplashPage` 배치가 피그마 새 배치(캐릭터 위, 로고 아래)로 바뀜. 버튼 문구는 피그마 "눌러서 시작하기" vs 앱 "시작하기" — 어느 쪽으로 할지 확인.
  - SVG는 `import X from '@/../assets/....svg'` 컴포넌트로 import (require 금지). 새 아이콘 파일명은 kebab-case.
- 피그마 쪽 작업 메모:
  - 원격 Figma MCP/플러그인 환경엔 Paperlogy 폰트가 없어서 텍스트 레이어 편집 불가 → 스플래시 프레임의 태그라인은 아웃라인 벡터(`3010:594`)로 들어가 있음. 문구 바뀌면 같이 수정 필요.
  - 모션 API 쓰려면 Figma 데스크톱 MCP(`figma-desktop`) 사용. 영상 확인은 `export_video` (프레임 추출용 ffmpeg는 이 맥에 없음).
